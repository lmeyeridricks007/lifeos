## Notes

- The Netherlands no longer uses a separate legal “city” status for most places; the official units are **gemeenten**. CBS lists **342** mainland municipalities (2025/2026).
- This file lists every municipality from the public municipal table (incl. Caribbean public bodies when present), with Yes/No for a dedicated ExpatLife city hub.
- **Dedicated page** = city hub under `/netherlands/{slug}/` registered in `NETHERLANDS_CITY_HUB_PAGES`.
- Job city pages (`/netherlands/work/jobs-in-*`) and Cities pillar shortlists are **not** counted as dedicated hubs.

## How to add a city hub

1. Add `src/data/cities/{slug}.ts` with `CityHubPageData`.
2. Add `app/netherlands/{slug}/page.tsx` rendering `CityHubTemplate`.
3. Register the dataset in `NETHERLANDS_CITY_HUB_PAGES`.
4. Add nav entries in `src/lib/nav/config.ts` if needed.
5. Update [`README.md`](./README.md) and this file.
