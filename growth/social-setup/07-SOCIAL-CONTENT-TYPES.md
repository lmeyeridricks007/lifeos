# 07 — Social content types

Standard types for ExpatCopilot. Prefer utility over announcement.

| Type | Format | Headline style | Body structure | CTA | Best channels |
|------|--------|----------------|----------------|-----|---------------|
| QUICK TIP | Single image / short caption | Imperative or “One thing…” | Tip → why it matters → caveat | Read guide | IG, FB, LI, TikTok |
| MYTH VS REALITY | Carousel 2–6 | “Myth: … / Reality: …” | Myth → reality → source habit | Guide/tool | IG, LI, Shorts |
| DATA POINT | Data card | Big number + unit | Number → meaning → verify | Dataset/tool | LI, IG, X |
| CITY COMPARISON | Carousel / pin | “A vs B for …” | Criteria → contrasts → who fits | City compare | IG, Pinterest, YT |
| SALARY EXAMPLE | Carousel / Short | “Gross ≠ take-home” | Scenario → steps → tool | Calculator | LI, YT, IG |
| CHECKLIST | Carousel / pin | “Before you …” | 5–7 ticks | Checklist page | IG, Pinterest, FB |
| COMMON MISTAKE | Single / carousel | “Common mistake: …” | Mistake → fix → link | Guide | All |
| EXPAT QUESTION | Text / Story | Question as headline | Answer in plain language | Soft guide | IG Stories, FB |
| HOW IT WORKS | Carousel 4–8 | “How X works in NL” | Steps 1…n → official verify | Guide | IG, LI, YT |
| TOOL DEMO | Short / screencast | “Check X in 60 seconds” | Hook → demo → result | Use tool | YT Shorts, TikTok, LI |
| NEW GUIDE | Link post | Specific outcome | What changed / who for | Read guide | LI, FB, X |
| POLICY UPDATE | Text + card | What changed / what didn’t | Calm facts → verify official | Updated guide | LI, X, FB |
| CULTURE EXPLAINER | Carousel / Short | Behavior-focused | Context → tip → respect | Culture guide | IG, TikTok |
| MOVING TIMELINE | Infographic | “From offer to arrival” | Phases | Moving hub | IG, Pinterest |
| BEFORE YOU MOVE | Checklist | Pre-departure focus | Tasks abroad | Document tool | IG, FB, email |
| AFTER YOU ARRIVE | Checklist | First weeks focus | Admin order | Survival guide | IG, FB |
| FAQ | Carousel | Question slides | Short answers | Hub | IG, YT |
| COMMUNITY QUESTION | Native text | Echo real question | Full answer; link last | Optional | Reddit, FB groups |

### Headline rules
- Specific > clever  
- No “ultimate” / “#1”  
- Numbers OK when true and sourced  

### Caption skeleton
1. Hook (problem or surprising clarity)  
2. 3–6 lines of substance  
3. Soft CTA + link if platform-appropriate  
4. Optional: “Not official advice—verify on government sites.”
