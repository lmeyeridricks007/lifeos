# 09 — Account security & governance

Avoid personal-only ownership. Prefer business email + shared vault + 2FA.

---

## Ownership principles

1. Create accounts with a **company email**, not a personal Gmail as sole owner.  
2. Store credentials in a **team password manager** (1Password/Bitwarden vault: `ExpatCopilot Social`).  
3. Enable **2FA** everywhere; save backup codes in the vault (secure note).  
4. Appoint **≥2 admins** where the platform allows.  
5. Document who owns Meta Business, LinkedIn Company, Google/YouTube Brand Account.  
6. Never share passwords via chat/email.

---

## Platform governance checklist

| Item | Requirement |
|------|-------------|
| Business email | `hello@` / `ops@` / `social@` on your domain |
| Password manager | Unique password per platform |
| 2FA | App-based preferred (not SMS-only if avoidable) |
| Recovery email | Secondary company inbox |
| Backup codes | Printed/encrypted in vault |
| Admin ownership | Two people minimum for Meta + LinkedIn + Google |
| Meta Business Suite | Page + IG in one Business portfolio |
| LinkedIn admins | Super admin + Content admin |
| YouTube | Brand Account; not only personal channel |
| Pinterest | Business account |
| TikTok | Business Center if ads later; Creator OK to start |
| Domain verification | Meta, LinkedIn, Pinterest, Google when offered |
| Offboarding | Remove ex-admins same day |

## Secure launch checklist

- [ ] Business email exists and is monitored  
- [ ] Password manager vault created  
- [ ] Meta Business portfolio created; 2FA on Meta  
- [ ] Facebook Page + Instagram attached; roles assigned  
- [ ] LinkedIn Company Page; ≥2 admins  
- [ ] Google account for YouTube Brand Account; 2FA  
- [ ] Pinterest Business + 2FA  
- [ ] TikTok + 2FA  
- [ ] X + 2FA  
- [ ] Backup codes stored  
- [ ] Recovery codes tested conceptually (know where they are)  
- [ ] No personal phone as sole 2FA without backup admin  
- [ ] Access log note: date created, primary owner
