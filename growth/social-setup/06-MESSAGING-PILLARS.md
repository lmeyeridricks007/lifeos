# 06 — Messaging pillars

Eight pillars for ExpatCopilot social. Rotate across the week; don’t force all platforms to cover all pillars.

---

## 1. MOVING TO NL

| Field | Detail |
|-------|--------|
| **Purpose** | Help people planning the move sequence |
| **Audience** | Considering / actively relocating |
| **Example topics** | Documents, timelines, EU vs non-EU, first decisions |
| **Best platform** | Instagram carousels, FB, LinkedIn, Reddit answers |
| **Best format** | CHECKLIST, MOVING TIMELINE, BEFORE YOU MOVE |
| **CTA** | Open moving hub / document readiness |
| **Commercial** | Medium |

## 2. MONEY & SALARY

| Field | Detail |
|-------|--------|
| **Purpose** | Clarify gross/net, costs, tax context |
| **Audience** | Professionals, HSM, established expats |
| **Example topics** | Net salary, 30% ruling orientation, COL |
| **Best platform** | LinkedIn, YouTube Shorts, Instagram data cards |
| **Best format** | SALARY EXAMPLE, DATA POINT, TOOL DEMO |
| **CTA** | Use salary / COL calculator |
| **Commercial** | High |

## 3. CITIES & HOUSING

| Field | Detail |
|-------|--------|
| **Purpose** | City choice and housing reality |
| **Audience** | Considering / relocating / families |
| **Example topics** | AMS vs RTM, rent expectations, city shortlists |
| **Best platform** | Instagram, Pinterest, YouTube, FB |
| **Best format** | CITY COMPARISON, COMMON MISTAKE |
| **CTA** | Compare cities |
| **Commercial** | Medium–high |

## 4. WORK & HSM

| Field | Detail |
|-------|--------|
| **Purpose** | Employment routes and HSM thresholds |
| **Audience** | HSM candidates, recruiters, HR |
| **Example topics** | HSM salary check, workplace culture, jobs orientation |
| **Best platform** | LinkedIn, YouTube Shorts |
| **Best format** | TOOL DEMO, HOW IT WORKS, POLICY UPDATE |
| **CTA** | HSM salary checker |
| **Commercial** | High |

## 5. HEALTHCARE & ADMIN LIFE

| Field | Detail |
|-------|--------|
| **Purpose** | Insurance and practical admin without fearmongering |
| **Audience** | Just arrived / actively relocating |
| **Example topics** | Health insurance basics, DigiD, registration |
| **Best platform** | FB, Instagram, communities |
| **Best format** | AFTER YOU ARRIVE, FAQ, HOW IT WORKS |
| **CTA** | Healthcare hub / DigiD guide |
| **Commercial** | Medium |

## 6. EDUCATION & FAMILY

| Field | Detail |
|-------|--------|
| **Purpose** | Schools and family logistics |
| **Audience** | Families, spouses |
| **Example topics** | School types, cities for families, childcare orientation |
| **Best platform** | FB, Pinterest, Instagram |
| **Best format** | CHECKLIST, FAQ |
| **CTA** | Education hub |
| **Commercial** | Medium |

## 7. DUTCH CULTURE & DAILY LIFE

| Field | Detail |
|-------|--------|
| **Purpose** | Reduce social friction; humanize the brand |
| **Audience** | Arrived / established |
| **Example topics** | Directness, etiquette, holidays, daily norms |
| **Best platform** | Instagram, TikTok (if active), FB |
| **Best format** | CULTURE EXPLAINER, MYTH VS REALITY |
| **CTA** | Culture / life guides |
| **Commercial** | Low |

## 8. TOOLS, CHECKLISTS & DATA

| Field | Detail |
|-------|--------|
| **Purpose** | Show product differentiation; earn saves/shares |
| **Audience** | All stages + journalists/partners |
| **Example topics** | Tool demos, official figures packaging, checklists |
| **Best platform** | All; LinkedIn/YouTube for demos; PR for data |
| **Best format** | TOOL DEMO, DATA POINT, NEW GUIDE |
| **CTA** | Try tool / cite dataset |
| **Commercial** | High (activation) |
