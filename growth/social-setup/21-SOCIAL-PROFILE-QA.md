# 21 — Social profile QA checklist

Run before first public posts and quarterly thereafter.

---

## Identity
- [ ] Handle matches canonical choice on every claimed network  
- [ ] Display name is **ExpatCopilot** (no “Official”)  
- [ ] Spelling consistent (ExpatCopilot)

## Branding
- [ ] Same avatar crop/logo everywhere  
- [ ] Covers/banners on-brand (colors from [`04`](./04-SOCIAL-VISUAL-GUIDELINES.md))  
- [ ] No low-res/pixelated logo  
- [ ] No unrelated stock-template look

## Copy
- [ ] Bios match approved variants ([`03`](./03-PROFILE-COPY.md))  
- [ ] No #1 / best / ultimate / official-gov claims  
- [ ] Disclaimer present where space allows (esp. YT/LinkedIn About)

## Links & tracking
- [ ] Profile URL → NL hub  
- [ ] UTMs present (`source`, `medium=social_profile`, `campaign=profile`)  
- [ ] Test links on mobile  
- [ ] CTA buttons point correctly (FB/LinkedIn)

## Contact & trust
- [ ] Business email only  
- [ ] Location set reasonably  
- [ ] Messenger/away message set if FB chat on  

## Permissions & security
- [ ] 2FA enabled  
- [ ] Backup codes in vault  
- [ ] ≥2 admins on Meta, LinkedIn, Google Brand  
- [ ] No sole personal ownership  

## Analytics
- [ ] Professional/Business dashboards on  
- [ ] YouTube Studio accessible  
- [ ] Pinterest/TikTok analytics path known if active  

## Domain
- [ ] Meta / LinkedIn / Pinterest / Google site association where offered  

## Content readiness
- [ ] ≥3 launch posts ready ([`19`](./19-LAUNCH-CONTENT-PLAN.md))  
- [ ] IG pins planned  
- [ ] Highlights plan (even if covers later)  
- [ ] No links to staged/404 URLs  

## Legal / disclosure
- [ ] Not implying government authority  
- [ ] Affiliate disclosure plan if commercial posts later  
- [ ] Reddit disclosure approach understood ([`17`](./17-REDDIT-IDENTITY-SETUP.md))
