# 01 — Social platform strategy

Aligns with [`../02-CHANNEL-PRIORITIZATION.md`](../02-CHANNEL-PRIORITIZATION.md): ExpatCopilot is an **information + tools** brand, not a lifestyle influencer operation.

---

## Classification key

| Label | Meaning |
|-------|---------|
| **CLAIM_NOW_AND_USE** | Create fully; publish on a light, sustainable cadence |
| **CLAIM_NOW_RESERVE** | Secure handle + profile; minimal or zero posts until capacity |
| **LAUNCH_LATER** | Skip until a named workstream is ready |
| **DO_NOT_PRIORITIZE** | Not worth brand/ops cost now |

---

## Effort model (active networks)

| Network | Target cadence (first 30 days) |
|---------|--------------------------------|
| Founder LinkedIn | 2 posts/week |
| LinkedIn Company | 1–2 posts/week (can share founder-originated) |
| Instagram | 2–3 posts/week (prefer carousels) |
| Facebook Page | 1–2/week (cross-post from IG OK) |
| YouTube Shorts | 0–2/week (only with script + capture) |
| Pinterest | 0 until 9 pins ready, then 3–5/week |
| TikTok / X | 0 unless reserved profile needs a single pin post |

---

## What “success” means for social setup

- Handles secured and consistent  
- Profiles trustworthy and non-hype  
- Links + UTMs correct  
- Security/ownership non-personal-only  
- Launch posts teach something useful  
- Ops load stays inside weekly growth cadence ([`../11-WEEKLY-OPERATING-CADENCE.md`](../11-WEEKLY-OPERATING-CADENCE.md))
