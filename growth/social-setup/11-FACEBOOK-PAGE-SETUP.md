# 11 — Facebook Page setup playbook

**Class:** CLAIM_NOW_AND_USE (official brand presence; light posting)

---

## Page vs Groups (critical)

| | **Facebook Page** | **Facebook Groups** |
|--|-------------------|---------------------|
| Role | Official ExpatCopilot presence, announcements, cross-posts | Where expats already ask questions |
| Ownership | You | Usually third-party communities |
| Priority | Brand completeness | **Distribution** (separate workstream) |
| Create our own Group? | — | **Not yet** — high moderation cost, weak until audience exists |

Do **not** create an ExpatCopilot Group in this setup phase unless community ops are staffed.

---

## Step-by-step

1. **Account type:** Facebook **Page** under Meta Business portfolio  
2. **Name:** ExpatCopilot  
3. **Handle:** `@ExpatCopilot`  
4. **Bio / About:** From [`03`](./03-PROFILE-COPY.md)  
5. **Category:** Education website / Website  
6. **URL:** NL hub + Facebook profile UTM  
7. **Profile image:** Logo mark  
8. **Cover:** Brand banner 1640×624  
9. **Contact:** Business email; optional Messenger (see below)  
10. **Privacy:** Page public; review visitor posts settings  
11. **Business settings:** Meta Business Suite; link Instagram  
12. **Analytics:** Meta Insights  
13. **Verification:** Meta domain verification when available  
14. **UTM:** About + CTA button  
15. **Admin/security:** ≥2 Page admins; 2FA  
16. **Launch readiness:** About complete; CTA Live; cover/avatar; first posts  

### CTA button
**Learn more** → Netherlands hub (UTM `utm_content=cta_button`)

### Messenger
- Default: **limited** — use away message: “We don’t provide personal case advice via chat. Browse guides at …”  
- Turn off if you cannot monitor.

### Moderation
- Filter profanity; hide hate  
- Delete spam and fake “official” impersonation comments  
- Don’t argue immigration cases in comments  

### Cross-posting
- Enable IG ↔ FB cross-post for feed where quality holds  
- Prefer editing captions for FB slightly longer  

### Cadence
1–2 posts/week (often shared from IG). Groups participation ≠ Page posting volume.
