## Fallback order (if `@ExpatCopilot` taken)

Evaluate for clarity, brandability, and non-spamminess:

| Rank | Handle | Verdict |
|------|--------|---------|
| 1 | `@ExpatCopilot` | **Preferred** — clear product name |
| 2 | `@ExpatCopilotNL` | Strong — NL focus without keyword stuffing |
| 3 | `@ExpatCopilotNetherlands` | Acceptable — long; OK on platforms with length room |
| 4 | `@GetExpatCopilot` | Weak — “Get” feels app-storey; use only if 1–3 gone |
| 5 | `@UseExpatCopilot` | Weak — same issue; last resort |

**Avoid:** `bestexpat…`, `officialexpat…`, `expat_copilot_nl_tips`, excessive underscores, “HQ”, “247”, year suffixes.

If the exact handle is parked/squatted: document evidence, use next fallback **consistently across all platforms**, and keep the display name **ExpatCopilot**.

## Bio naming conventions

- Lead with **what you help with**, not slogans  
- Mention **Netherlands** once  
- Mention **guides / tools** once  
- Optional: **cities · salary · moving** as short tokens  
- End with soft CTA or site  

---

## Consistency rules

1. Same handle string everywhere if possible.  
2. Same avatar crop everywhere.  
3. Same primary link destination family (NL hub + UTMs).  
4. Same spelling: **ExpatCopilot** (camel case in prose; no “Expat Copilot” in usernames).  
5. If one platform forces a fallback, **do not** mix `@ExpatCopilot` on IG and `@ExpatCopilotNL` on YouTube—pick one fallback globally.  
6. Store the chosen handle in the password manager note “Canonical social handle”.
