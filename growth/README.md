---

## Purpose

This folder is the **master operating system** for acquiring traffic and authority **beyond organic Google search alone**.

It turns ExpatCopilot’s guides, tools, and data into a repeatable loop:

useful assets → distribution → citations/backlinks → referral + rankings → more users → email + sharing → stronger assets

Use these docs to run weekly growth work, train collaborators, and feed later workstreams (templates, calendars, outreach packs).

---

## Growth philosophy

1. **Utility first.** Promote things people need during a move (checklists, calculators, official figures)—not brand slogans.
2. **Search is the flywheel, not the only engine.** Community + PR + partners feed SEO; SEO feeds retention and email.
3. **Earn the link and the mention.** No spammy backlink asks; no cold-dropping URLs in groups.
4. **One strong asset, many channels.** Repurpose ruthlessly; don’t invent parallel content empires.
5. **Tiered effort.** Do Tier 1 deeply before spreading thin across Instagram/Pinterest/YouTube.
6. **Measure outcomes that compound:** referring domains, tool use, email, referral sessions—not vanity followers.
7. **Stay trustworthy.** Sound practical and informed; never pose as government; never overclaim.

## Definition of success (first 90 days)

| Outcome | Success looks like |
|---------|-------------------|
| **Process** | Weekly cadence running; inventory ≥30 scored assets; dashboards filled |
| **Distribution** | Consistent community presence without spam flags; 8–12 useful posts/replies per week across Reddit/FB |
| **Authority** | Active outreach pipeline; first quality links/mentions landing |
| **Capture** | Newsletter live with clear lead magnet; measurable signups |
| **Compounding** | At least one asset reused across ≥5 channels with tracked UTMs |
| **SEO** | GSC monitoring healthy; no growth tactics that create soft-404s or spam signals |
