# 04 — Content Distribution Model

**Goal:** One strong ExpatCopilot asset → many channel-native pieces → one CTA family → tracked distribution → refresh.

---

## Workflow

```
SOURCE ASSET
    → EXTRACT ANGLES (3–7)
    → CHANNEL ADAPTATION
    → CTA (from CTA library)
    → DISTRIBUTION (+ UTM)
    → TRACKING
    → REFRESH (30/90 days)
```

### Step details

| Step | Owner action | Output |
|------|--------------|--------|
| **SOURCE ASSET** | Pick from inventory (promo value ≥4) | URL + one-sentence utility |
| **EXTRACT ANGLES** | List facts, myths, steps, numbers, stories | Angle sheet |
| **CHANNEL ADAPTATION** | Rewrite per channel norms | Drafts in `templates/` |
| **CTA** | One primary CTA; optional soft secondary | CTA IDs from `08` |
| **DISTRIBUTION** | Post/send per cadence | Live links + dates |
| **TRACKING** | UTMs + sheet row | Metrics snapshot |
| **REFRESH** | Update numbers / relink / reshare | Version note |

## Channel adaptation map

| Channel | Format | Length | Link style | Proof |
|---------|--------|--------|------------|-------|
| LinkedIn | Text + insight | 120–220 words | 1 link end or comment | Experience / data |
| Instagram carousel | 6–10 slides | Very short | Bio / story link | Visual clarity |
| Facebook page | Native post | Short | 1 link | Local utility |
| Reddit | Answer-first comment/post | As needed | Link only if asked or clearly additive | Sub rules |
| Facebook **group** | Helpful reply | Short–medium | Often no link first; link when valuable | Group rules |
| Pinterest | Vertical pin | Title + 2 lines | Destination URL | Search keywords |
| Newsletter | 1 block | 80–150 words | Button/link | Why this week |
| YouTube Short | 30–45s script | Spoken | Spoken URL / description | Demo |
| YouTube long | Outline | 6–12 min | Description chapters | Walkthrough |
| PR pitch | Email | 5–8 sentences | Asset URL + 1 chart | Newsworthiness |
| Partner resource | 1-pager brief | Bullets | Canonical URL | Employee benefit |
| Backlink pitch | Email | 6–10 sentences | Specific page | Fit to their article |
| Founder LinkedIn | Personal voice | 150–250 words | Soft link | Founder story |

## Reusable adaptation checklist

- [ ] Same claim as website (no overclaim)  
- [ ] Channel tone from `07-BRAND-COMMUNICATION-GUIDELINES.md`  
- [ ] CTA from `08-CTA-LIBRARY.md`  
- [ ] UTM: `utm_source`, `utm_medium`, `utm_campaign`, `utm_content`  
- [ ] No staged/404 URLs  
- [ ] Disclosure if commercial  

### UTM convention

```
utm_source = reddit | facebook | linkedin | newsletter | partner | pr | pinterest | youtube
utm_medium = community | social | email | referral | organic_social
utm_campaign = {asset-slug}-{yyyy-mm}
utm_content = {format}-{variant}   # e.g. carousel-a, comment-thread
```

## Capacity rule

Per week (solo / small team):

- **1** hero asset  
- **≤2** communities deeply  
- **≤3** social adaptations  
- **≤5** outreach emails  
- **1** newsletter block (when list exists)
