# 06 — Campaign Playbooks

Repeatable campaign types. Each assumes a **live, indexable** hero asset (never promote staged 404s).

Shared success metrics (pick 3–5 per campaign): referral sessions, tool completions, email signups, referring domains, ranked query movement, partner clicks.

---

## 1. DATA RELEASE

| Field | Detail |
|-------|--------|
| **Goal** | Earn citations + referral; strengthen authority |
| **Audience** | Journalists, bloggers, researchers, established expats |
| **Hero asset** | Official figures / unique dataset page |
| **Channels** | PR email, LinkedIn, newsletter, Reddit (careful), partners |
| **Social** | Chart card + 3 takeaways |
| **Community** | “What’s surprising in the latest figures?” + link to methodology |
| **Email** | “New data: 5 numbers that change planning” |
| **PR angle** | Fresh packaging of public/official stats with clear method |
| **Backlink angle** | “Replace outdated salary/COL stats with this table” |
| **Partner angle** | Embed chart in HR newsletter |
| **CTA** | Cite / explore the dataset |
| **Metrics** | Mentions, links, referral sessions, branded search |

## 2. CITY COMPARISON

| Field | Detail |
|-------|--------|
| **Goal** | Capture city-intent traffic; tool usage |

| **Channels** | SEO, Reddit, FB groups, Pinterest (later), newsletter |

| **Backlink** | City blogs / “best places” roundups |
| **Partner** | Relo firms’ city briefing links |
| **CTA** | Compare Dutch cities |
| **Metrics** | Tool starts/completes, city guide clicks |
