# 07 — Linking rules

**Prefer deep links.** Homepage links are almost never ideal.

---

## Classifications

| Class | Meaning | Example |
|-------|---------|---------|
| **DIRECT_HELPFUL** | Link completes the help | Net salary calculator for “what’s net on 75k?” |
| **OPTIONAL_SUPPORTING** | Nice-to-have after full answer | City compare after AMS vs RTM criteria |
| **TOOL_REQUIRED** | Can’t reasonably paste full output | Document readiness / COL calculator |
| **SOURCE_REFERENCE** | Cite methodology/data page | Official figures packaging |
| **NOT_NEEDED** | Text answer enough | “Yes, health insurance is generally mandatory after arrival—confirm timing on official sites.” |
| **AVOID_SELF_PROMOTION** | Rules or context forbid | “No links” groups; heated housing scam thread where any site looks shady |

---

## Good vs bad

**Good**  
Q: What would €75k gross be net?  
A: Explain that net depends on situation; give qualitative expectations; then: tool link + “Affiliation: I run ExpatCopilot” + remind it’s an estimate.

**Bad**  
“Use ExpatCopilot.com”

---

## By destination type

| Destination | Rule |
|-------------|------|
| Homepage | Avoid |
| Guide deep link | OK when question matches |
| Tool / calculator | Best justified class |
| Data / research | OK for journalists/data threads |
| Affiliate / commercial | **Avoid** in communities |
| Official gov | Prefer alongside or instead of us |

---

## Frequency caps

- ≤1 ExpatCopilot link per comment  
- Soft cap: link in ≤~25–30% of your weekly comments  
- Per community: several helpful no-link replies before first link (see 30-day plan)

UTMs: `utm_source=reddit` or `facebook`, `utm_medium=community`, campaign = topic slug.
