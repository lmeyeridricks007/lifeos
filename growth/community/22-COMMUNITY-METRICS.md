## What to track (outcomes)

| Metric | Notes |
|--------|--------|
| Community referral sessions | UTM `utm_medium=community` |
| Engaged referral sessions | Bounce/engagement filter |
| Tool completions from community | Analytics segment |
| Newsletter signups | Soft CTA only |
| Return visits | Branded / direct later |
| Community mentions | Manual note |
| Helpful reply engagement | Replies > raw karma |
| Content gaps discovered | CSV count |
| Posts/links removed | Keep near 0 |
| Mod warnings | Keep at 0 |
| Brand mentions (unprompted) | Qualitative win |
| Earned backlinks | Rare; log if any |

---

## Conservative targets

| Horizon | Targets |
|---------|---------|
| **30 days** | Cadence running; ≥8–10 link-free helps; ≥5 gaps logged; **0** removals/warnings; referral traffic optional |
| **60 days** | Steady 2–4 answers/week; selective links working; first measurable UTM sessions; gap→backlog habit |
| **90 days** | Small but clean referral stream; ≥1 improved page/tool from community demand; still ≤~25–30% linked replies |

Do not chase volume if removals rise—pause links.
