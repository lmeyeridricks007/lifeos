# 05 — Question / intent taxonomy

Use this when classifying threads (monitoring + scoring). Asset types map to site hubs/tools—prefer live deep URLs when linking.

**Link columns:**  
- **Link OK** = when a deep link can add real value after a full answer  
- **Link skip** = text/official sources enough; linking looks promotional
