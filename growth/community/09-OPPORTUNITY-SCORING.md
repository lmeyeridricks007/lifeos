# 09 — Opportunity scoring

Score each candidate thread **1–5** (5 = best), except **Risk** where 5 = most risky.

| Dimension | 1 | 5 |
|-----------|---|---|
| Relevance | Off-topic | Core NL expat move/settle |
| Answerability | Can’t help safely | Clear practical answer |
| Traffic potential | Dead thread | Active, discoverable |
| Community value | Me-too | Unlocks others’ confusion |
| Asset fit | Nothing on site | Perfect live deep link/tool |
| Commercial potential | None | Tools/partners (still be ethical) |
| Content-gap value | Already covered | Strong new page/tool signal |
| Promo risk | Safe / no-link | High ban/self-promo risk |

**Overall (directional):**  
`(Relevance + Answerability + Community value + Asset fit + Gap value + Traffic/5) − Promo risk`  
Then apply judgment.

---

## Classes

| Class | When |
|-------|------|
| **ANSWER_NOW** | High help, low risk, you can reply today |
| **ANSWER_NO_LINK** | Help yes; link would hurt or isn’t needed |
| **ANSWER_WITH_RESOURCE** | Full answer + justified deep link + disclosure |
| **CONTENT_RESEARCH** | Don’t reply yet; log gap / wording |
| **MONITOR** | Interesting but timing/risk wrong |
| **SKIP** | Drama, off-topic, can’t add value, or too late |
