# 19 — 30-day Reddit / community launch

**Do not optimize for aggressive volume.**

---

## Week 1 — Observe

- Finalize identity & bio  
- Read rules for mapped communities  
- Join/lurk only where appropriate (you do this manually later)  
- Save 10 example threads (no replies required)  
- Set up trackers  

**Links:** none  

## Week 2 — Helpful comments only

- 6–10 link-free helpful comments total  
- Spread across ≥3 community types  
- Log everything  

**Links:** none (unless a mod explicitly asks for a resource)

## Week 3 — Selective resources

- Continue mostly link-free  
- Up to 2–3 disclosed deep links where class = ANSWER_WITH_RESOURCE  
- First mod outreach if desired ([`21`](./21-MODERATOR-OUTREACH.md))  

## Week 4 — Optional original post + review

- 0–1 high-value original post if earned  
- Review removals (target 0), referral UTMs, gaps logged (≥5)  
- Decide steady-state cadence  

---

## Thresholds before promotional links

| Gate | Minimum |
|------|---------|
| Link-free helpful comments (account) | ~8–10 |
| Per strict community | Several helps before first link |
| Removals | 0 recent |
| Disclosure | Always when linking |

## Success (conservative)

- Habit formed; no mod trouble  
- ≥5 content gaps logged  
- Any referral traffic is bonus—not required in 30 days
