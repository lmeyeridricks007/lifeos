# 10 — Content gap loop

```
QUESTION
 → classify intent
 → check ExpatCopilot coverage
 → answer community (if appropriate)
 → identify gap
 → backlog
 → improve/create resource
 → answer future questions better
```

Use `content-gap-template.csv`.

| Field | Notes |
|-------|--------|
| question | Anonymized paraphrase OK |
| community | Category or verified name |
| date | Observed |
| topic | Taxonomy intent |
| frequency_observed | 1st / recurring |
| current_coverage | URL or “none” |
| gap_severity | 1–5 |
| recommended_action | refresh / new guide / new tool / FAQ block |
| suggested_page_tool | Proposed path |
| seo_keyword_overlap | Queries people type |
| priority | P0–P3 |

**Rule:** Community demand does not justify thin spam pages. Only ship resources that meet site quality bars.
