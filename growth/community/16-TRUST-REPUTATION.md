# 16 — Trust & reputation

---

## Track (qualitative + light quantitative)

| Signal | Good | Bad |
|--------|------|-----|
| Helpfulness | Thanks, follow-ups | Ignored / “this is an ad” |
| Reception | Upvotes/likes in context | Downvotes + removals |
| Mod feedback | Silence or thanks | Warnings |
| Link share | Rare, accepted | Frequent, removed |
| Removals | ~0 | Rising |

Do **not** optimize blindly for karma.

---

## Red flags — pause linking / review approach

- High removal rate  
- Repeated mod warnings  
- Links in too many replies  
- Copy-paste language  
- Brand-first answers  
- Conflict with norms  
- Users questioning honesty of disclosure  

**Response:** Stop links for 2+ weeks; return to pure help; message mods if needed (apologetic, not defensive).
