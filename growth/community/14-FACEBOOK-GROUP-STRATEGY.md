# 14 — Facebook group strategy

**Scope:** Participation in third-party groups only.  
**Not in scope:** Facebook Page setup ([`../social-setup/11-FACEBOOK-PAGE-SETUP.md`](../social-setup/11-FACEBOOK-PAGE-SETUP.md)).  
**Do not** create an ExpatCopilot Group yet.  
Companion detail: `docs/backlinks/promotions/facebook-outreach-and-groups.md`.

---

## Group types

| Type | Notes |
|------|--------|
| Expat general | Broad Q&A; strict promo rules common |
| City | Housing-heavy; scam sensitivity |
| Nationality-specific | High trust if respectful; origin guides |
| Parents | Tone warm; careful on schools/childcare |
| Students | Budget; anti-spam |
| Professional / HSM | Salary/HSM precision; LinkedIn-like tone |

---

## Operating rules

| Action | Rule |
|--------|------|
| Joining | Use real profile; answer screening questions honestly |
| Introducing | Only if group culture welcomes; no pitch |
| Answering | Value-first comments from personal profile usually |
| Posting | Rare; prefer comments unless mods welcome resources |
| Linking | Often banned—default no link; ask mods ([`21`](./21-MODERATOR-OUTREACH.md)) |
| Page sharing into groups | Usually spammy—avoid |
| Moderator permission | Ask before sharing checklists/tools |
| Resource sharing | One deep link + disclosure + offer to remove |

---

## Example mod ask (short)

> Hi — I help run ExpatCopilot (practical NL relocation guides/tools). Would it be OK to share a free checklist/tool when it directly answers a member’s question, with clear disclosure? Happy to follow any rules you prefer (including no links).
