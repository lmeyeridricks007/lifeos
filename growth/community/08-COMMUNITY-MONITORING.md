# 08 — Community monitoring

Manual / AI-assisted. **No scraping infrastructure. No auto-posting.**

---

## What to notice

| Signal | Action |
|--------|--------|
| New useful questions | Score ([`09`](./09-OPPORTUNITY-SCORING.md)) |
| Recurring pain points | Content gap row |
| High-engagement threads | Learn wording; don’t pile on late |
| Policy confusion | Calm correction + official source |
| Misinformation | Correct carefully; no pile-ons |
| Tool opportunities | Backlog |
| We already answer well | Optional deep link later |
| We answer poorly / not at all | Gap → create/improve |

---

## Daily (15–25 min)

1. Open saved searches / feeds for 3–5 priority communities (manual)  
2. Skim new questions; star 2–4 candidates  
3. Score quickly: ANSWER_NOW vs SKIP  
4. If answering today: draft → human edit → post  
5. Log in tracker  

## Weekly (45–60 min)

1. Review tracker: removals, gaps, themes  
2. Update opportunity list  
3. Feed 3 gaps into product/SEO backlog  
4. Check GA4 community UTM referrals  
5. Adjust next week’s focus intents  

---

## AI assist (optional)

May: categorize pasted public URLs/text you provide; suggest ExpatCopilot URLs; draft replies; cluster repeats; score opportunities.  

Must not: fetch private content autonomously; post; hide affiliation.

Human approval required for every public interaction.
