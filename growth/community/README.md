## WHEN LINKS ARE ALLOWED

- Question needs a **tool** (net salary, HSM check, city compare, checklist) you can’t paste fully  
- Deep link **directly** answers the ask  
- Community rules allow links **and** you’ve earned trust (often after link-free help)  
- You **disclose** affiliation  

## WHEN LINKS SHOULD NOT BE USED

- Simple factual answer fits in a comment  
- Rules ban links / self-promo  
- You’ve already linked recently in that community  
- Urge is promotional, not helpful  
- Topic is high-risk legal/tax/medical and a homepage pitch would mislead

## FIRST 10 ACTIONS

1. Read participation rules ([`04`](./04-PARTICIPATION-RULES.md)) and high-risk topics ([`17`](./17-HIGH-RISK-TOPICS.md))  
2. Finalize Reddit identity bio ([`03`](./03-REDDIT-OPERATING-MODEL.md))  
3. Copy tracker CSVs; set up a private sheet  
4. Build verified community map (names from public search + existing FB doc — no scraping)  
5. Observe 1 week: upvote/save, don’t answer yet if new account  
6. Draft taxonomy bookmarks for intents you know well  
7. Answer **link-free** only for week 2  
8. Log every interaction in the tracker  
9. Open content-gap rows for repeated unanswered themes  
10. Only then consider selective deep links with disclosure

## RISK RULES (non-negotiable)

No bots · no multi-account sockpuppets · no fabricated experience · no mass link drops · no arguing with mods · no legal/tax/medical conclusions · disclose affiliation · human approve every public reply

## AI ASSISTANCE RULES

**AI may:** categorize questions, suggest EC URLs, draft replies, summarize threads, score opportunities, log gap reports.  
**AI must not:** post, create accounts, join communities, impersonate, fabricate experience, mass-message, hide affiliation, or scrape private groups.  
**Every public reply needs human approval.** Detail: [`23-AI-ASSISTANCE-RULES.md`](./23-AI-ASSISTANCE-RULES.md)
