# 03 — Audience Segments

Use this to choose **hero asset, channel, lead magnet, and CTA** before promoting.

Commercial value is directional (1–5): likelihood of affiliate/partner/tool engagement or B2B interest—not a promise of revenue.

---

## Segment cards

### 1. Considering moving to the Netherlands
| Field | Detail |
|-------|--------|
| **Needs** | Feasibility, cost, visa routes, cities, timeline |
| **Questions** | Can I move without a job? What does it cost? Which city? |
| **High-value content** | Moving hub, cost guides, visa compare, country-from pages |
| **Best channels** | SEO, Reddit, FB groups, Pinterest (later), LinkedIn |
| **Lead magnet** | “Move feasibility checklist” / cost planner PDF |
| **Best CTA** | Start with the moving guide / cost calculator |
| **Commercial value** | 3 |
